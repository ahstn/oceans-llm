These pages describe what the gateway does with each request in detail. Use them when you need exact behaviour, not setup steps. For configuration fields, start at the [configuration reference](/configuration/).

- [Provider API compatibility](/reference/provider-api-compatibility/): which public API families each provider type supports, and how the gateway translates requests, streams and usage for each upstream API.
- [Request lifecycle and failure modes](/reference/request-lifecycle/): the steps a request goes through, and the errors callers can get at each step.
