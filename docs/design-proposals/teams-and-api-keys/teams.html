What changed

  1. 1PR-ledger anatomy. InsightCard with a toolbar, one bordered table, a pinned right column, and a row-limit footer.
  2. 2The row is the toggle. Clicking anywhere expands it, like the PR rows. "Show 1 member" buttons go away; avatar stacks show who is on the team at a glance.
  3. 3Actions move into a ⋯ menu in the pinned column (Edit team, Add members, Copy key), so the two always-visible buttons per row are gone.
  4. 4Members become a nested table in a bg-muted/40 detail panel, like the PR commit table. Transfer and Remove sit in a per-member menu, with a side rail for every tag, the admins, and the team key.
  5. 5"No admins" becomes a filter in the Filter menu.

Tag display options

Teams carry up to five key:value tags. The row has to stay one line tall.

A · Two chips, then +N Recommended

One line every time. The first two tags in saved order stay visible; the rest are one hover away. Chips are filter shortcuts.

B · Count only
__TAG__5 tags

The quietest row, but you can't scan for cost-center without hovering every row.

C · Promote a tag key to a column
Columns ▸cost-centerownerenv

A Columns popover, as on Models, turns an org-wide key into a sortable column. Pairs well with A, and is a follow-up once tag keys settle.
