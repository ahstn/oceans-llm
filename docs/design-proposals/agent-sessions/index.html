Agent session detail — 3 design proposals

Alternative layouts for the agent session monitoring surface. Each mockup uses the same real session data (27 Jul 2026, 22:02–22:31, 10 requests, US$3.96, 5.1 min active of 29.0 min elapsed). See README.md for the efficiency review of the current drawer.

A — Triage Drawer

Recommended first

Keeps the current Sheet. Sticky KPI header, segmented efficiency bar, tabs (Overview / Activity / Diagnostics) replace the long scroll. Merged activity timeline removes the duplicated request tables.

B — Session Report Page

Deep-link target

Full route with stat cards, a Gantt-style request timeline that makes the 23.9 min of idle gaps visible, token mix bar, and a right rail for identity and versions.

C — Ops Console

Glance view

Dense no-scroll console: active-time ratio gauge, traffic-light health chips, single chronological feed with explicit idle-gap markers. Pattern reusable on the sessions list.
