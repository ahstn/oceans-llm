Oceans LLM is a gateway that sits between your organisation's AI clients and the model providers and MCP servers they use. Coding agents, applications, and scripts call one API with an Oceans key. Admins decide, in one place, which models and tools each caller can reach, how much they can spend, and what gets logged.

Without a gateway, every client has to manage its own provider keys, budgets, and audit trail. Oceans takes those jobs off the clients, so adding a provider or changing a policy doesn't mean touching every tool that uses it.

## Who these docs are for

- **Admins** run Oceans and use its admin UI to manage providers, models, users, teams, and budgets. Most of these docs are for you.
- **Users** are the people with an Oceans identity. They sign in, create API keys, and connect their agents.
- **Callers** are the software that sends requests with an API key, such as a coding agent or a CI job.

If you work on Oceans itself, the [contributing docs](https://github.com/ahstn/oceans-llm/tree/main/docs/contributing) cover the codebase, releases, and tests.
